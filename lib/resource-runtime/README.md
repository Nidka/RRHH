# Bibliotecas de soporte para recursos

Estas DLL permiten que MSBuild procese los recursos WinForms serializados de la
aplicación recuperada sin tener que descargar paquetes de Internet.

Proceden de `System.Resources.Extensions` 8.0.0 y de su cadena oficial de
dependencias para .NET Framework:

- `System.Resources.Extensions.dll`
- `System.Memory.dll`
- `System.Buffers.dll`
- `System.Numerics.Vectors.dll`
- `System.Runtime.CompilerServices.Unsafe.dll`

Son componentes de Microsoft/.NET distribuidos bajo licencia MIT. El origen del
paquete principal es <https://www.nuget.org/packages/System.Resources.Extensions/8.0.0>.
