REF-005 · RangoFechas

Un permiso que contiene a otro ya no pasa

Antes · RRHHClass.ExistePermiso
WHERE "IdEmpleado" = @empleadoId AND (@inicio::date BETWEEN "FechaInicio"::date AND "FechaFin"::date OR @fin::date BETWEEN "FechaInicio"::date AND "FechaFin"::date); // existente 10–12, nuevo 9–13: // ni 9 ni 13 caen dentro → se acepta ✗
Después · RangoFechas.Solapa
public bool Solapa(RangoFechas otro) { return Desde <= otro.Hasta && Hasta >= otro.Desde; } // igualdad, cruce parcial y contención // contiguos sin día común: no solapan // 7 requerimientos reutilizan esta regla ✓
T3 · Refactorización14
Explicación en 20 s. La regla original solo miraba si el inicio o el fin del permiso nuevo caían dentro de uno existente. Un permiso del 9 al 13 contiene al del 10 al 12 y pasaba. La condición correcta es inicio1 ≤ fin2 y fin1 ≥ inicio2. Está una sola vez, en el dominio, y la usan siete requerimientos.
