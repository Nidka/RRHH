# REF-003: motivos de permiso por capas

## 1. Problema inicial

FrmMantMotivo mezclaba carga de controles con consultas y ejecutaba Update durante Load; cancelar podía haber escrito. El alta usaba Max sobre tabla potencialmente vacía y edición reconstruía campos no editables.

## 2. Evidencia antes

Fuente Git `01db40b^:Software/RecursosHumanos/RecursosHumanos/FrmMantMotivo.cs`, método `private void FrmMantMotivo_Load`. Código extraído con git show, sin reconstruirlo de memoria:

```csharp
	private void FrmMantMotivo_Load(object sender, EventArgs e)
	{
		if ((idMotivo != 0 && idTipo != 0) ? true : false)
		{
			Motivo_Perm motivo_Perm = Motivo_PermMapper.Instance().SelectBy([SpecialName] (Motivo_Perm V) => V.idMotivo == idMotivo).First();
			UcTxtMotivo.Text = motivo_Perm.Descrip_Motivo;
			CheckEdit1.EditValue = motivo_Perm.Salario;
			UcTxtAbreviatura.Text = motivo_Perm.Abrev;
			Motivo_PermMapper.Instance().Update(motivo_Perm);
		}
	}
```

## 3. Solución aplicada

Vista pasiva que reenvía eventos, presenter que coordina casos y repositorio específico PostgreSQL creado en CompositionRoot. Se conservan nombres de formularios y controles. Mantenimiento preventivo por separación de responsabilidades; correcciones de comportamiento se declaran aparte en la spec TEC correspondiente.

## 4. Evidencia después

Fuente Git `01db40b:Software/RRHH.Presentation/Permisos/MotivoPermisoEditorPresenter.cs`, método `private void Cargar`:

```csharp
    private void Cargar()
    {
        _cargado = false;
        _view.HabilitarGuardar(false);
        try
        {
            if (_view.IdMotivo > 0)
            {
                MotivoPermisoDto motivo = _obtener.Ejecutar(_view.IdMotivo);
                if (motivo.TipoPermisoId != _view.IdTipoPermiso)
                {
                    _view.MostrarError("El motivo no pertenece al tipo seleccionado. Actualice el listado.");
                    return;
                }
                _view.MostrarMotivo(motivo);
            }
            _cargado = true;
            _view.HabilitarGuardar(true);
        }
        catch (Exception ex) { _view.MostrarError("No se pudo cargar el motivo: " + ex.Message); }
    }
```

## 5. Principio aplicado

SRP: FrmMantMotivo.Load deja de decidir persistencia; MotivoPermisoEditorPresenter.Cargar coordina ObtenerMotivoPermiso. DIP: casos/presenter consumen contrato IMotivoPermisoRepository; pruebas usan FakeMotivoPermisoRepository.

## 6. Beneficio y comprobación

Cancelar/cargar se prueba sin efectos de escritura; edición conserva campos fuera del editor. MotivosPresenterTests y MotivoPermisoPostgreSqlTests verifican errores, roles, referencias y preservación de UnaVezPorAnio. Las pruebas complementarias de esta sesión en la rama de cierre de motivos registran 293 correctas (net8, PostgreSQL local ficticio); no equivalen a ejecutar estas pantallas en Windows. Ver [validación RF-04/05](../evidencias/RF-04/validacion-local.txt). El resultado de compilación/QA original se conserva en T2; no se inventan capturas o revisiones nuevas.
